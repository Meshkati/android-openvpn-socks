Connection profiles

Save several setups and switch between them. A profile is one whole route, the same things you set up today: an OpenVPN profile with its sign-in and, if you want, a VLESS server. Home gets a profile picker at the top of the route card. Everything else stays where it is.

Principles

  • A profile is a whole route, saved under a name.
  • Home always shows which profile Connect will use. Switching takes two taps.
  • The OpenVPN and VLESS screens stay as they are. They edit the profile in use, or the one you opened from Profiles.
  • With only one profile, Home gets one new line and nothing else changes.

Screens

  1. Home: the route card starts with the profile in use new
  2. Picker: a bottom sheet to switch, add or manage new
  3. Profiles: the list, with rename, duplicate, delete new
  4. Profile: one profile's name and route new
  5. OpenVPN profile, VLESS server, Log: as today

Not changing

  • Connect flow, VPN prompt, service, routes, log and IP check.
  • The authenticator code is still never saved.
  • Everything is still saved on this phone only.
  • Items marked optional can be dropped without breaking the rest.

Home and the picker

The route card gets a header row with the profile in use. Tapping it opens the picker. The rest of the card is today's card, filled from that profile.

Managing profiles

Opened from "Manage profiles" in the picker. Changes save as you go, the same way the setup screens save today. Changes to the profile in use apply on the next connect, as today.

Dark theme, widget, notification

The profile name shows up wherever the app already names the servers.

Considered: chips on Home

The other place a switcher could go. Not recommended as the only switcher, but it could be added later.

Why the picker

The header row costs one line on Home and works the same with 2 profiles or 20. The sheet has room to show each profile's route, and it gives "New profile" and "Manage profiles" a natural place.

The chips are faster when someone switches several times a day between two or three profiles. If that turns out to be common, chips could show above the card once there are 2–3 profiles, with the picker still on the header.

After the update

Today's settings become the first profile, named after the OpenVPN server (vpn.example.com), or "My profile" if the .ovpn has no remote line. Nothing has to be set up again.

Deleting

Deleting the profile in use switches to the first one left in the list. Deleting the last profile takes Home back to "Not set up". Undo brings back everything, password included.

Privacy

Crash reports hide the servers, UUIDs and usernames of every profile, not only the one in use. Profiles are stored the same way as today: unencrypted, in app-private storage, never sent anywhere.

Storage

One SharedPreferences file per profile (profile_<id>), plus the order and the profile in use in settings. Settings.profile, .vless and the rest keep their names and read the profile in use, so the service, widgets and setup screens change little.

Questions before implementation

The sketches show the first option of each. The line marked in green is my recommendation.

1. What to call them

The app already calls the .ovpn file an "OpenVPN profile", so a "Work" profile would contain an "OpenVPN profile".

ProfilesRename the .ovpn screen and rows to "OpenVPN config". "Profiles" is the word people look for.
PresetsNothing else changes, but it's a less familiar word for this.

2. What a profile holds

The whole routeOpenVPN, sign-in and VLESS together, as sketched. Simple, and Duplicate covers "same OpenVPN, other VLESS".
Pick OpenVPN and VLESS separatelyTwo saved lists, and a profile points to one of each. No copies when many profiles share one .ovpn, but more screens and more to explain.

3. Switching while connected

Reconnect with the new profileAs in frame 3. Stops at the code field when the new profile needs a code.
Disconnect firstRows greyed out while connected, like the Use VLESS switch. Less code, one more step.

4. Widgets

Follow the profile in useAs sketched. No widget setup screen.
One profile per widgetChosen when placing it, so you can keep a Work and a Travel button side by side. Adds a widget configuration screen.

5. Left out of this draft

  • Sharing or exporting a profile. It would carry the password and the VLESS UUID.
  • Switching profiles by Wi-Fi network.
  • A Quick Settings tile.
