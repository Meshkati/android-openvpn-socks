OpenVPN → VLESS UI sketches

Today everything is on one scrolling form: profile text, sign-in, code, VLESS link, the Connect button, status and the raw log. The proposal keeps every feature and splits them by how often you touch them. Connecting happens on the home screen, setup is one tap away, and the log has its own screen.

Principles

  • One action on the home screen: the round button connects and disconnects.
  • Home shows what is set up (server names), not the raw profile or link.
  • The authenticator code field appears only when the profile has static-challenge.
  • Status in plain words. Raw OpenVPN and Xray messages stay in the log.
  • Light and dark follow the system setting.

Screens

  1. Home: toggle, status, your route (OpenVPN → VLESS), code field when needed.
  2. OpenVPN profile: import or edit the .ovpn, username and password.
  3. VLESS server: share link or Xray JSON, with a read-only summary.
  4. Log: the same log as today, full screen.

Not changing

  • No new settings, protocols, profiles lists or routing options.
  • Same storage (Settings), same service, same connect flow and VPN prompt.
  • Items marked optional are small conveniences. Each can be dropped.

Home

One screen, five states. They come from the existing VpnState phases and the detail text the service already reports.

Setup

Opened from the route rows. Changes save automatically when you go back, the same as today's save on onStop. Changes made while connected apply on the next connect, as today.

Log, dark theme, notification

The log moves off the home screen. Dark theme uses the same layout with its own palette.

Where each current control goes

Every control on today's screen has a place. Nothing is removed.

Questions before implementation

1. Toolkit

The app has no AndroidX today. My recommendation: keep it that way and build this with framework views, the DeviceDefault day/night theme and a few drawables. Material Components or Jetpack Compose would be quicker to style but add dependencies and APK size.

2. Accent colour

Fixed teal (as sketched) everywhere, or the wallpaper colour on Android 12+ with teal on older phones?

3. Optional items

Keep or drop: plain-language error text, Paste button, log Copy button, log filter chips.
